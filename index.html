Smart Parking and Space Monetization

Drivers find and pay for unused private and society parking on WhatsApp. Owners get paid automatically.

  • n8n
  • Gemini
  • WhatsApp API
  • PostgreSQL / Sheets
  • Razorpay
How it works
  1. n8n captures the driver's location and Gemini understands the request.
  2. Live spot availability is checked in the database.
  3. The booking is confirmed and a UPI/Razorpay link is sent.
  4. Owner payout and platform commission are logged.

AI Flatmate Compatibility and Onboarding

Matches flatmates on budget, location and lifestyle, then verifies IDs and sends the agreement.

  • Python
  • n8n
  • Gemini
  • SQLite / Airtable
  • OCR / ID API
How it works
  1. Preferences come in through an intake form.
  2. A Python scoring engine with Gemini calculates a compatibility percentage.
  3. When there is a match, n8n runs automatic ID verification.
  4. An intro meetup is scheduled and a rental agreement template is sent.

Hyperlocal Ad-Space and Vendor Distribution

Local brands put trackable QR ads on tea cups, bottles and bags carried by nearby street vendors.

  • n8n
  • Gemini
  • Dynamic QR API
  • Sheets / CRM
  • WhatsApp / Email
How it works
  1. A brand submits a campaign through a portal.
  2. Trackable dynamic QR codes are generated for cups, bottles and bags.
  3. Print and delivery orders go to nearby vendors automatically.
  4. Scans are tracked live and monthly vendor payouts are calculated.
